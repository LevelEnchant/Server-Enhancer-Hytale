2. Continue until the folder you are in shows `setup`.
3. Launch `setup` in the folder where you found it.

# Common problems

**Missing setup file due to folder structure.** The `setup` file may be located in a nested folder. Please navigate one level down until you find `setup` alongside the other files.

**SmartScreen returned for the new zip.** A new file counts, to Windows, as a new download.

**Update your shortcut.** If you have moved the folder, run `setup` from the new location to refresh your shortcut.

**The old link did not follow the move.** Ignore the leftover link and launch `setup` inside the folder you moved to.

**Path Too Long Error.** Windows may report that the path is too long when trying to access files. To resolve this, extract the contents closer to the root of the drive.
